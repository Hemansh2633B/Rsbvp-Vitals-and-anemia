## 2. Bugs found and fixed during Sprint 12

Real defects, each now covered by a test that fails without the fix.

1. **Duplicate samples made the effective rate unmeasurable.** With 50 % duplicated
   frames (a 60 Hz read loop on a 30 fps sensor), the *median* interval is ~0, so
   the rate was reported as "unknown" instead of the true frame rate next to a
   duplicate warning. Both implementations now derive the rate from intervals
   between distinct frames.
2. **A single stall escaped detection.** One 120 ms stall in 300 samples barely
   moves the coefficient of variation (0.21), so an irregular capture was reported
   as regular. A stall is now detected from the interval itself (≥ 2.5× median),
   independent of the CV.
3. **The Python verdict ignored duplicates and stalls.** `trace_report()`
   computed them, but `assess_window()` only checked rate and maximum gap, so the
   research pathway would accept a window the browser rejected. Both now
   short-circuit to `irregular_timestamps`.
4. **`audit_rows` crashed on an empty dataset** (`UnboundLocalError`, a leaked
   comprehension variable). Empty-directory audits are a normal case for a
   project without an authorized dataset.
5. **The benchmark report carried no software provenance** — no git commit, no
   platform, no estimator configuration. Added, with `null`/`unknown` rather than
   guessed values when information is unavailable.

## 3. Fixtures: what they are and what they are not

`tests/fixtures/rppg_disturbance_*.csv` (8 files, ~76 KB each) are generated by
`tests/fixtures/generate_rppg_disturbance_fixtures.py` with a fixed seed and are
byte-reproducible (a test re-runs the generator and compares bytes).

| Fixture | Observed verdict | Rejection reason |
|---|---|---|
| `clean_72bpm` | **valid** | — (baseline must still pass) |
| `second_pulse_competing` | low_signal_quality | `weak_separation_1.03` |
| `no_pulse_noise` | low_signal_quality | `low_concentration_0.073`, `weak_separation_1.22` |
| `clipped_channels` | low_signal_quality | `acquisition_clipping_or_flat`, `no_spectral_peak` |
| `flat_channel` | low_signal_quality | `no_spectral_peak` |
| `illumination_step` | low_signal_quality | `low_concentration_0.062` |
| `motion_burst` | low_signal_quality | `low_concentration_0.159` |
| `missing_roi_samples` | valid (forehead) | left cheek absent 5–12 s → 64.8 % coverage |

The last row is deliberate: a defect confined to one ROI must not invalidate an
untouched ROI, and it must not be hidden either — the per-ROI coverage reports it.

**These verdicts say the gates behave as designed on synthetic input.** They say
nothing about real skin, lighting, motion or measurement accuracy, and no number
above may be quoted as an accuracy result.
